# Музыкальный Telegram-бот (Яндекс Музыка) — контекст для Claude

## Кто владелец и как с ним общаться
- Владелец не программист. Отвечать **по-русски, простыми словами**, давать пошаговые
  инструкции «куда нажать», команды — отдельными блоками для копирования.
- Компьютер владельца — **Windows**. Бот запускается двойным щелчком по `start.bat`.
- Никогда не просить присылать в чат токены, пароли, ключи API. Если владелец прислал
  секрет — посоветовать отозвать/перевыпустить его.
- Перед большой работой — коротко объяснить план; после — что проверено и что нет.

## Что это
Изначально FastAPI-бэкенд для Telegram Mini App с музыкой из VK. ВКонтакте закрыл доступ
к аудио для сторонних приложений (vkhost: «application is blocked», Kate Mobile:
«Unknown method passed», вход по паролю — flood-блокировка), поэтому основной источник —
**Яндекс Музыка** (библиотека `yandex-music`). Код VK оставлен (`MUSIC_SOURCE=vk`).

Бот: aiogram 3.24, `app/bot/`, запуск `python -m app.bot` (или вместе с API, `RUN_BOT`).
Имя бота: один токен, два username — `@YanVKMusik_bot` и `@YanMusicapp`
(показываемое имя задаёт `BOT_USERNAME` в `.env`).

### Функции (всё сделано и проверено на имитациях Telegram/Яндекса)
- Поиск песен → список → MP3 в чат (`handlers.py`, `deliver_track`), кеш file_id по `bot_id`.
- **🌊 Моя волна** (`_send_wave`): 10 песен альбомом (плеер Telegram играет подряд),
  «Ещё 10» / «Новая волна», режимы diversity, сессии ротора Яндекса с очередью
  уже присланных песен (без повторов).
- **Личная волна**: каждый может подключить свой Яндекс (`/yandex`, device code на
  ya.ru/device, `accounts.py`). Без подключения — волна по истории в боте через основной
  аккаунт в режиме инкогнито.
- **🎭 Настроение** (moodEnergy + станции «для спорта/сна»).
- **📈 Чарты**, **🧹 Очистить чат** (удаляет присланные песни, Telegram — только < 48 ч).
- **👥 Друзья** (`friends.py`): взаимная дружба по ссылке `?start=f_<id>` или `@username`,
  запрет приглашений, архив последних 50 песен, карточка друга.
- **💌 Посвящения и реакции** (`social.py`), **🤝 совместимость и волна на двоих** (`duo.py`).
- **🎮 Игры** (`games.py`): угадай мелодию (15-сек отрывок без тегов, `audio.make_clip`),
  «Чей это трек?», батл треков, рейтинг.
- **Inline-режим** (`inline.py`): `@бот запрос` в любом чате; включено в @BotFather
  (`/setinline` + `/setinlinefeedback`).
- `/recommend` удалён по просьбе владельца.
- **Лимит песен и ⭐ Премиум** (`premium.py`): `DAILY_SONG_LIMIT` (по умолчанию **0 —
  лимит выключен**, владелец хочет сначала набрать аудиторию). Подписка через Telegram
  Stars: `PREMIUM_STARS=20` за 30 дней (`create_invoice_link`, `subscription_period`),
  автопродление, отключение продления (`edit_user_star_subscription`), `/premium`,
  `/paysupport`. Без лимита: Премиум, `ADMIN_IDS`, свой Яндекс с Плюсом. Пока лимит
  выключен, Премиум не продаётся, команды не показываются в меню.

### Данные
- Без `MONGO_URL` — mongomock в памяти + автосохранение в `bot_data.json` каждые 30 с.
- С `MONGO_URL` — MongoDB; при первом старте `bot_data.json` переносится в пустую базу
  (файл переименовывается в `.imported`). Индексы создаются при старте.
  История — последние 500 записей на человека.

## Где сейчас работает бот (состояние на 08.11.2026)
- **Сервер h1cloud, Германия** (Ubuntu 24.04, тариф Basic 2 ГБ), имя `stellar-fox`.
  Установлен через `deploy/install.sh` в `/opt/musicbot`, сервис `musicbot` (systemd,
  автоперезапуск), **MongoDB 8 установлена и подключена**, Telegram работает.
  Консоль — веб-консоль h1cloud (кнопка «Вставить текст»).
- **Проблема:** Яндекс Музыка отвечает **451 Unavailable For Legal Reasons** серверам
  в Германии. Проверка показала вход аккаунта `painperfect`, «Плюс: нет» — уточнить у
  владельца, на каком аккаунте подписка (может быть искажено регионом).
- **Решение в процессе:** «мост» в Россию — `deploy/bridge.sh` (tinyproxy на российском
  сервере, слушает только localhost; SSH-туннель с немецкого сервера; `YANDEX_PROXY=
  http://127.0.0.1:8888` в `.env`). Владелец выбирает дешёвый российский VPS
  (Timeweb Premium дорогой; смотрели Selectel-подобный конструктор — советовали 30% vCPU,
  1 ГБ, почасовую оплату).
- **Важно:** в 2026 году Telegram в России замедляют/ограничивают. Если с российского
  сервера `curl -s -o /dev/null -w "%{http_code}" https://api.telegram.org` даёт число,
  а не `000`, — можно перенести бота целиком в Россию и отказаться от немецкого сервера.

## Следующие шаги
1. Российский сервер: проверить доступ к Telegram (команда выше).
2. Если Telegram недоступен: на немецком сервере `sudo bash install.sh` (обновление),
   затем `sudo bash /opt/musicbot/deploy/bridge.sh` → IP и пароль российского сервера.
   В конце должна пройти проверка `check_yandex.py` («✅ Песни скачиваются»).
3. Если доступен: поставить бота на российский сервер (`install.sh`), перенести данные
   (`mongodump`/или `bot_data.json`), остановить сервис на немецком.
4. Потом по желанию владельца: Mini App (нужен https-адрес, сервер), лимит скачиваний
   VK как второй источник (если ВК вернёт аудио). Включение лимита — по решению владельца.

## Полезное
- Обновить бота на сервере: `sudo bash install.sh` (в домашней папке root).
- Логи: `journalctl -u musicbot -f`; перезапуск: `systemctl restart musicbot`.
- Проверка Яндекса: `sudo -u musicbot /opt/musicbot/venv/bin/python check_yandex.py`
  (из `/opt/musicbot`).
- Тесты в этом проекте делались скриптами с подменой `Bot.__call__` и `ClientAsync`
  (имитация Telegram и Яндекса) через `dp.feed_update`; локальный MP3 отдавался
  `python -m http.server`.
