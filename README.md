# 🎧 VK Music Bot API

Backend API для Telegram Mini App, позволяющий искать и скачивать музыку из ВКонтакте.

## 🚀 Возможности

- 🔍 **Поиск треков** с обложками альбомов
- ⬇️ **Скачивание MP3** напрямую с серверов VK
- 🎯 **Персональные рекомендации** на основе истории прослушиваний
- 🔐 **Безопасная авторизация** через Telegram WebApp InitData
- 📊 **История прослушиваний** для каждого пользователя
- 🤖 **Встроенный Telegram-бот**: поиск, отправка MP3 прямо в чат, рекомендации

## 📋 Требования

- Python 3.11+
- MongoDB
- FFmpeg (для конвертации аудио)

## 🪟 Быстрый запуск на Windows (без программирования)

1. Установите Python с [python.org](https://www.python.org/downloads/),
   при установке отметьте **Add python.exe to PATH**.
2. Скачайте проект ZIP-архивом и распакуйте.
3. Дважды щёлкните `start.bat`. При первом запуске он установит компоненты,
   спросит токен бота и источник музыки (Яндекс Музыка — вход по коду
   на ya.ru/device, или ВК), затем запустит бота.

MongoDB не обязательна: без `MONGO_URL` данные (друзья, архивы, подключённые
аккаунты) хранятся в памяти и сохраняются в файл `bot_data.json` каждые 30 секунд.
При переносе бота в новую папку скопируйте `.env` и `bot_data.json`.
В `bot_data.json` лежат токены подключённых аккаунтов Яндекса — не передавайте его никому.

## 🛠 Установка

1. **Клонируйте репозиторий**

```bash
git clone <your-repo-url>
cd music-bot
```

2. **Создайте виртуальное окружение**

```bash
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. **Установите зависимости**

```bash
pip install -r requirements.txt
```

4. **Настройте переменные окружения**

```bash
cp .env.example .env
# Отредактируйте .env и добавьте свои токены
```

5. **Запустите MongoDB**

```bash
# macOS (через Homebrew)
brew services start mongodb-community

# Linux
sudo systemctl start mongod

# Docker
docker run -d -p 27017:27017 mongo
```

## 🎮 Запуск

### Development режим

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

```bash
# с --workers > 1 выключите встроенного бота (RUN_BOT=false) и запустите его отдельно: python -m app.bot

```

## 🤖 Telegram-бот

Бот (aiogram 3) живёт в `app/bot/` и по умолчанию запускается вместе с API
(`RUN_BOT=true`). Он использует те же `VKService` и MongoDB, поэтому история
прослушиваний и рекомендации общие для бота и Mini App.

Что умеет:

- текстовое сообщение → список треков с пагинацией;
- нажатие на трек → MP3 в чат (HLS-потоки `m3u8` собираются через ffmpeg);
- «🌊 Моя волна» (`/wave`) → 10 песен из «Моей волны» Яндекса одним альбомом:
  встроенный плеер Telegram играет их подряд. Перед новой волной старая
  удаляется из чата, «▶️ Ещё 10» продолжает волну;
- Личная волна: каждый может подключить свой Яндекс (`/yandex`, вход по коду
  на ya.ru/device) и получать свою «Мою волну»; с Плюсом песни скачиваются
  через его подписку. Без подключения волна строится по истории человека в боте
  через основной аккаунт в режиме инкогнито (рекомендации владельца не портятся);
- Inline-режим: `@бот название` в любом чате → список песен, выбранная песня
  отправляется прямо в этот чат. Включите в @BotFather `/setinline` и
  `/setinlinefeedback`. Человек должен хотя бы раз открыть бота;
- «🎭 Настроение» (`/mood`) → волна под настроение: бодрое, весёлое, спокойное,
  грустное (настройка moodEnergy) и для спорта / для сна (станции занятий Яндекса);
- Посвящения: под песней «💌 Посвятить другу» → анонимно или от своего имени,
  с подписью; друг отвечает «❤️ Спасибо». Только друзьям, анонимные можно запретить;
- Реакции 🔥 ❤️ 😂 😢 на песни из архива друга: уведомление и счётчик в архиве;
- Карточка друга: архив, «🤝 Совместимость» (процент по истории в боте, общие
  исполнители и песни) и «🌊 Волна на двоих» по любимым песням обоих — другу
  приходит приглашение включить её у себя;
- «🎮 Игры» (`/games`): 🎵 угадай мелодию (15 секунд из середины песни без тегов,
  4 варианта), 🕵️ «Чей это трек?» (песня из архива друга), ⚔️ батл треков
  (турнир 4 песен участников с голосованием) и 🏆 рейтинг друзей;
- «📈 Чарты» (`/chart`) → чарт Яндекс Музыки;
- «🧹 Очистить чат» (`/clear`) → удаляет присланные ботом песни (Telegram
  разрешает боту удалять сообщения не старше 48 часов);
- «👥 Друзья» (`/friends`) → взаимные друзья и их архив последних 50 песен.
  Добавить друга: по личной ссылке-приглашению или отправив боту `@username`;
  дружба появляется только после того, как второй человек нажмёт «Принять».
  Кнопка «🔕 Запретить приглашения» в меню друзей отключает входящие заявки
  (и отменяет ожидающие), «🔔 Разрешить приглашения» включает их снова;
- если задан `WEBAPP_URL`, показывает кнопку «🎧 Открыть плеер» и menu button Mini App.

Отправленные файлы кешируются по `file_id` (коллекция `tg_audio`), поэтому
повторная отправка трека мгновенная.

**Запуск отдельно от API** (обязательно при `uvicorn --workers > 1`, иначе
несколько процессов будут одновременно опрашивать Telegram):

```bash
# в .env: RUN_BOT=false
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
python -m app.bot
```

## 🔑 Получение токенов

### Telegram Bot Token

1. Напишите [@BotFather](https://t.me/BotFather)
2. Создайте нового бота командой `/newbot`
3. Скопируйте полученный токен в `.env`

### Яндекс Музыка (по умолчанию)

```bash
python get_yandex_token.py
```

Программа покажет код — введите его на странице Яндекса в браузере.
Для полных треков нужна подписка Яндекс Плюс, без неё — 30-секундные отрывки.
Источник выбирается переменной `MUSIC_SOURCE` (`yandex` / `vk`).

### VK Token

Приложения на vkhost.github.io (VK Admin, Kate Mobile) VK заблокировал
(`application is blocked`). Получите токен по логину и паролю:

```bash
python get_vk_token.py
```

Скрипт спросит логин, пароль и код подтверждения, проверит доступ к музыке
и выведет строки `VK_TOKEN=...` и `VK_USER_AGENT=...` для `.env`.

## 🌐 API Endpoints

### 🔐 Authentication

- `POST /api/auth/login` - Авторизация через Telegram
- `POST /api/auth/history` - Добавить трек в историю

### 🎵 Music

- `GET /api/music/search?q={query}` - Поиск треков
- `GET /api/music/download/{track_id}` - Скачать MP3
- `GET /api/music/recommendations` - Получить рекомендации

## 🐛 Troubleshooting

### MongoDB не подключается

```bash
# Проверьте статус
brew services list  # macOS
sudo systemctl status mongod  # Linux

# Проверьте порт
lsof -i :27017
```

### VK API возвращает пустые результаты

- Убедитесь, что используете **VK Admin** токен
- Проверьте, что токен не истек
- Попробуйте получить новый токен
